Ответы на контрольные вопросы

1. В чём разница между transition и animation?
transition плавно изменяет свойство при переходе между состояниями, например при :hover. animation позволяет создавать полноценную последовательность изменений с помощью @keyframes.

2. Какие свойства можно анимировать в CSS?
Можно анимировать многие свойства: color, background, opacity, transform, width, height, margin, padding и другие.

3. Для чего используется transform?
Для изменения положения, размера, поворота или наклона элемента. Например: scale(), rotate(), translate().

4. Как задать плавность анимации?
Для transition используется функция времени, например:

transition: transform 0.3s ease;

Для animation можно использовать:

animation: rotate 2s linear infinite;

5. Что означает параметр infinite?
Он означает, что анимация будет повторяться бесконечно.

6. Как задать задержку перед началом анимации?
С помощью animation-delay:

animation-delay: 2s;

7. Чем отличаются функции времени ease, linear, ease-in-out?

ease — плавное начало и завершение;
linear — постоянная скорость;
ease-in-out — плавное начало, ускорение и плавное завершение.

8. Можно ли объединять несколько анимаций для одного элемента?
Да. Несколько анимаций можно указать через запятую:

animation: move 2s infinite, rotate 3s infinite;

9. Как работает animation-iteration-count?
Оно определяет количество повторений анимации:

animation-iteration-count: 3;

А значение:

animation-iteration-count: infinite;

запускает бесконечный повтор.

10. Какие плюсы и минусы CSS-анимаций по сравнению с JavaScript-анимациями?
Плюсы CSS-анимаций — простота, небольшой объём кода и хорошая производительность для стандартных эффектов. Минус — CSS имеет меньше возможностей для сложной интерактивной логики, где JavaScript предоставляет значительно больше контроля.
